# DPC School Website

Welcome to the **DPC School** website repository.

## 📌 Project Overview
This repository contains the codebase for the DPC School website. It serves as the central hub for school information, admissions, academic programs, student & parent notices, event updates, and community resources.

---

## 🚀 Getting Started

### Clone the Repository
```bash
git clone https://github.com/adtechenterprisespvtltd2/dpc-school-website.git
cd dpc-school-website
```

### Branching Strategy & Collaboration
- **`main`**: Production-ready code.
- Feature branches: `feature/<feature-name>`
- Bugfix branches: `fix/<issue-name>`

Please create a branch for your tasks and open a Pull Request against `main`.
